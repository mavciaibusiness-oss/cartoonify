## 0. Open questions for the operator

Each has a default; the spec is written to the default. Say if you want the other answer before approving.

- **Q1. KVKK stays at its file path, served at `/tr/kvkk` by a rewrite.** The standards checker finds legal pages only at `app/(group)/<name>/page.tsx`; a `tr/` folder in the path hides the page from it, which would block every turn ("required page kvkk does not exist") and switch off the KVKK structure check. Default: **the KVKK page stays at `app/(tr)/(legal)/kvkk/page.tsx`; `middleware.ts` answers `/kvkk` with a 301 to `/tr/kvkk` and serves `/tr/kvkk` from that file by an internal rewrite.** The other Turkish pages move under `app/(tr)/tr/`. The checker then reads privacy, terms, cookies and contact from the English drafts and KVKK from the Turkish page. The checker's blind spot is filed as a system finding (suggested_next), not worked around anywhere else. Alternative: move KVKK too and ask for a checker change first (blocks this task).
- **Q2. Where the English footer sends "KVKK".** Default: **`/tr/kvkk`, labelled "KVKK notice (Turkish)".** The language switch on `/tr/kvkk` sends English readers to `/privacy`.
- **Q3. The "Türkçe'ye geç" bar.** Default: shown on English pages when the browser's **first** language starts with `tr`; one line with a link to the same page in Turkish and a close button; closing it hides it for the browser tab's session (`sessionStorage` key `pth-lang-hint`, which the cookie policy names). No redirect, no cookie, nothing sent to the server. Alternative: never remember the close.
- **Q4. What the legal text says about the e-mail hash.** The code keeps a **plain SHA-256** of the normalised address (`supabase/migrations/20261027000000_protoolhub_wallet.sql`, `claim_welcome`, `v_key := encode(sha256(...))`), not a keyed hash. Anyone who already knows an address can recompute it, so the text must not call it anonymous or keyed. Default: **the KVKK and privacy texts say exactly that: a SHA-256 hash of the address, not the address itself, kept after account deletion.** A keyed hash would need a migration and a rehash of the existing keys; it goes to the backlog.
- **Q5. "2 days" for the IP and device hashes.** The code blanks `welcome_grants.ip_hash` and `device_hash` for grants older than yesterday, **at the next welcome claim**, not on a timer (same migration, `claim_welcome`, `where g.granted_on < v_today - 1`). On a quiet site that can be later than two days. Default: **the text says the hashes are used for 2 days and then deleted, and that the deletion runs automatically at the first free-allowance claim after that period.** That is accurate. Alternative: a scheduled cleanup (a migration with `pg_cron`; a later task).
- **Q6. The default site address.** Default: **`DEFAULT_SITE_URL` in `lib/env.ts` becomes `https://cartoon.protoolhub.net`**, so canonical links, `hreflang`, the sitemap and robots name the new domain. You also set `NEXT_PUBLIC_SITE_URL` in Production (§7) to the same value. Previews then carry canonical links to the new domain, which is correct for search engines. `.mavci/project.json` `deploy.site_url` is not an agent's file; update it after go-live (G10).
- **Q7. Mascot spend.** Default: **four renders at `quality: "high"`, estimated 4 × 0.12 = 0.48 USD, hard ceiling 0.90 USD for the task** (room for up to three single re-renders). Nothing is spent before you approve the PLAN HASH (G3). The model is the project's `IMAGE_MODEL` (`gpt-image-2.5-sunburst`). If the API refuses `background: "transparent"`, the script stops on the first call with no image and no charge; the orchestrator comes back with a one-line amendment to `data/mascot-0025.json` (`"background": "opaque"`) for your approval.
- **Q8. The withdrawal-right wording.** The refund page states that the statutory right of withdrawal does not apply to digital content delivered at once (Turkey: Mesafeli Sözleşmeler Yönetmeliği, Article 15; EU: Directive 2011/83/EU, Article 16(m)). **D2. `middleware.ts`** (repository root; new). It runs only on four patterns and does three things:

```ts
import { NextResponse, type NextRequest } from 'next/server'

export const config = { matcher: ['/en', '/en/:path*', '/kvkk', '/tr/kvkk'] }

export function middleware(request: NextRequest) {
  const { pathname, search } = request.nextUrl
  if (pathname === '/tr/kvkk') return NextResponse.rewrite(new URL('/kvkk' + search, request.url))
  if (pathname === '/kvkk') return NextResponse.redirect(new URL('/tr/kvkk' + search, request.url), 301)
  const rest = pathname === '/en' ? '/' : pathname.slice(3)
  return NextResponse.redirect(new URL(rest + search, request.url), 301)
}
```

The `config.matcher` line is pinned character for character (criterion 139). Middleware sees only the incoming address, so the rewrite to `/kvkk` is not redirected again. No `next.config.mjs` change. `process.env` is not read in middleware.

## 5. The mascot pipeline (operator-gated, paid)

### 5.1 Why a new script

`scripts/render-jobs.mjs` is built around style previews: items are `[style, variant, subject]`, it renders with `images.edit` on an approved source photo, writes `lib/preview-manifest.json`, and `--promote` refuses until the style catalogue equals the choices. A mascot has no source photo, no style id and no catalogue entry. Bending that script would touch a file criterion 22 freezes and that 0019–0024's criteria hold. So the mascot gets its own small script, `scripts/render-mascot.mjs` (§5.3), with the same discipline: a data file approved in this spec, a free `--plan` that prints a **PLAN HASH**, a paid `--render` that refuses without that hash and stops before passing the ceiling, a free `--choose`, and a free `--promote` that writes the web files and records their hashes. The builder cannot write `scripts/` or `data/`; the orchestrator copies both blocks byte for byte (G2), and criterion 143 compares them.

### 5.2 Costs and the data file

- Model: `IMAGE_MODEL` from `lib/image-constraints.ts` (`gpt-image-2.5-sunburst`), `images.generate` (no input image), `1024x1024`, `quality: "high"`, `background: "transparent"`, PNG.
- Estimate: **0.12 USD per image** (no input image; the script records the real cost from `usage` with 0024's rates). Four candidates: **about 0.48 USD**. **Hard ceiling: 0.90 USD for the task**; the script also caps any data file at 1.00 USD. Before each call it refuses if spent + 0.12 would pass the ceiling; after each call it stops if the cost is unknown or the ceiling is passed.
- Output: `assets/mascot/0025/A.png` … `D.png` (masters, kept in the repo), `reports/0025-mascot.json` (every call: file hash, prompt hash, usage, cost, time; the choice; the promoted files' hashes).
- Web files from the chosen master (sharp, `fit: contain`, transparent padding, WebP, quality stepped down from 86 until under the limit): **`public/brand/mascot-480.webp`, 480 × 480, at most 60 000 bytes** (shown at 240 CSS px, sharp on 2× screens) and **`public/brand/mascot-240.webp`, 240 × 240, at most 20 000 bytes** (shown at 120 CSS px on the profile).

### 5.3 The script

The orchestrator writes this block to `scripts/render-mascot.mjs`. It never prints the key, never writes outside `assets/mascot/0025/`, `reports/0025-mascot.json` and `public/brand/mascot-*.webp`, and does not mention the preview folders (criterion 53 scans `scripts/`).

```js render-mascot-0025
/**
 * Task 0025: the ProToolHub Cartoon mascot, rendered with OpenAI behind operator gates.
 *
 *   --plan                                         FREE. The four prompts, the estimate and the PLAN HASH.
 *   --render --approved-plan <hex> [--only <A-D>]  PAID. Renders every candidate not yet rendered, or the one
 *                                                  named by --only again. Refuses unless the plan hash matches
 *                                                  and the next call stays under the ceiling.
 *   --choose <A-D>                                 FREE. Records the operator's choice (all four must exist).
 *   --promote                                      FREE. Writes public/brand/mascot-480.webp and mascot-240.webp
 *                                                  from the chosen candidate and records their hashes.
 *   --status                                       FREE.
 *
 * The key is read through lib/env.ts only and is never printed.
 *   node --env-file=.env.local --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/render-mascot.mjs --plan
 */
import crypto from 'node:crypto'
import fs from 'node:fs'
import path from 'node:path'
import { fileURLToPath } from 'node:url'
import sharp from 'sharp'

const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..')
const DATA_REL = 'data/mascot-0025.json'
const REPORT_REL = 'reports/0025-mascot.json'
const OUT_DIR_REL = 'assets/mascot/0025'
const WEB = [
  { rel: 'public/brand/mascot-480.webp', size: 480, maxBytes: 60000 },
  { rel: 'public/brand/mascot-240.webp', size: 240, maxBytes: 20000 },
]
const HARD_CEILING_USD = 1.0
const RATES = { text_input_per_m: 5, image_input_per_m: 8, image_output_per_m: 30 }
const IDS = ['A', 'B', 'C', 'D']
const QUALITIES = [86, 78, 70, 62, 54]

const abs = (rel) => path.join(ROOT, ...rel.split('/'))
function fail(message) { console.error('render-mascot: ' + message); process.exit(1) }
const sha256 = (b) => crypto.createHash('sha256').update(b).digest('hex')
const usd = (n) => (typeof n === 'number' ? n.toFixed(4) + ' USD' : 'unknown')
function costOf(usage) {
  if (!usage || typeof usage.input_tokens !== 'number' || typeof usage.output_tokens !== 'number') return null
  const d = usage.input_tokens_details || {}
  const text = typeof d.text_tokens === 'number' ? d.text_tokens : 0
  const image = typeof d.image_tokens === 'number' ? d.image_tokens : usage.input_tokens - text
  return Math.round(((text * RATES.text_input_per_m + image * RATES.image_input_per_m + usage.output_tokens * RATES.image_output_per_m) / 1e6) * 1e6) / 1e6
}

const DATA_TEXT = fs.readFileSync(abs(DATA_REL), 'utf8').split('\r\n').join('\n')
const DATA = JSON.parse(DATA_TEXT)
const PLAN_HASH = sha256(DATA_TEXT)
const CEILING = Math.min(Number(DATA.ceiling_usd), HARD_CEILING_USD)
const ESTIMATE = Number(DATA.estimate_usd_per_image)
if (!(CEILING > 0) || !(ESTIMATE > 0)) fail(DATA_REL + ' has no valid ceiling or estimate')
if (!Array.isArray(DATA.candidates) || DATA.candidates.map((c) => c.id).join() !== IDS.join()) fail(DATA_REL + ' must hold candidates A, B, C, D in that order')
const promptOf = (id) => DATA.base_prompt + ' ' + DATA.candidates.find((c) => c.id === id).prompt

function load() {
  if (!fs.existsSync(abs(REPORT_REL))) return { task: DATA.task, plan_sha256: PLAN_HASH, ceiling_usd: CEILING, candidates: {}, discarded: [], chosen: null, promoted: null }
  return JSON.parse(fs.readFileSync(abs(REPORT_REL), 'utf8'))
}
function save(r) {
  fs.mkdirSync(path.dirname(abs(REPORT_REL)), { recursive: true })
  fs.writeFileSync(abs(REPORT_REL), JSON.stringify(r, null, 2) + '\n')
}
const spent = (r) => Object.values(r.candidates).concat(r.discarded).reduce((s, c) => s + (typeof c.cost_usd === 'number' ? c.cost_usd : 0), 0)
function checkFile(c) {
  if (!fs.existsSync(abs(c.file))) fail(c.file + ' is missing')
  if (sha256(fs.readFileSync(abs(c.file))) !== c.sha256) fail(c.file + ' does not match its recorded hash')
}

const args = process.argv.slice(2)
const has = (name) => args.indexOf(name) >= 0
const value = (name) => { const i = args.indexOf(name); return i >= 0 && i + 1 < args.length ? args[i + 1] : null }

function plan() {
  console.log('task ' + DATA.task + ': ' + DATA.purpose)
  console.log('size ' + DATA.size + ', quality ' + DATA.quality + ', background ' + DATA.background + ', PNG')
  for (const id of IDS) console.log('\n' + id + ': ' + promptOf(id))
  console.log('\nestimate: ' + IDS.length + ' x ' + usd(ESTIMATE) + ' = ' + usd(IDS.length * ESTIMATE) + '; ceiling ' + usd(CEILING))
  console.log('PLAN HASH ' + PLAN_HASH)
}

async function render() {
  if (value('--approved-plan') !== PLAN_HASH) fail('the approved plan hash does not match; run --plan and approve its PLAN HASH')
  const only = value('--only')
  if (only !== null && IDS.indexOf(only) < 0) fail('--only takes A, B, C or D')
  const r = load()
  if (r.plan_sha256 !== PLAN_HASH) fail(REPORT_REL + ' was written for another plan')
  if (r.chosen) fail('a candidate is already chosen; nothing more is rendered')
  const todo = only ? [only] : IDS.filter((id) => !r.candidates[id])
  if (!todo.length) { console.log('all four candidates are rendered; use --only <id> to render one again'); return }
  if (spent(r) + ESTIMATE > CEILING) fail('the next render would pass the ceiling of ' + usd(CEILING) + ' (spent ' + usd(spent(r)) + ')')
  const { getEnv } = await import('../lib/env.ts')
  const { IMAGE_MODEL } = await import('../lib/image-constraints.ts')
  const { default: OpenAI } = await import('openai')
  const openai = new OpenAI({ apiKey: getEnv().OPENAI_API_KEY, timeout: 300000, maxRetries: 0 })
  fs.mkdirSync(abs(OUT_DIR_REL), { recursive: true })
  for (const id of todo) {
    if (spent(r) + ESTIMATE > CEILING) fail('the next render would pass the ceiling of ' + usd(CEILING) + ' (spent ' + usd(spent(r)) + ')')
    const prompt = promptOf(id)
    const started = Date.now()
    const result = await openai.images.generate({ model: IMAGE_MODEL, prompt, size: DATA.size, quality: DATA.quality, background: DATA.background, output_format: 'png' })
    const b64 = result && result.data && result.data[0] && result.data[0].b64_json
    if (!b64) fail(id + ': the answer holds no image')
    const out = Buffer.from(b64, 'base64')
    const rel = OUT_DIR_REL + '/' + id + '.png'
    if (r.candidates[id]) r.discarded.push(Object.assign({ id }, r.candidates[id]))
    fs.writeFileSync(abs(rel), out)
    const usage = result.usage ?? null
    const cost = costOf(usage)
    r.candidates[id] = { file: rel, sha256: sha256(out), prompt_sha256: sha256(Buffer.from(prompt)), model: IMAGE_MODEL, size: DATA.size, quality: DATA.quality, background: DATA.background, usage, cost_usd: cost, latency_ms: Date.now() - started, at: new Date().toISOString() }
    save(r)
    console.log(id + '  ' + rel + '  ' + usd(cost) + '   spent ' + usd(spent(r)) + ' of ' + usd(CEILING))
    if (typeof cost !== 'number') fail(id + ' recorded no usage; stopping')
    if (spent(r) > CEILING) fail('spent ' + usd(spent(r)) + ', over the ceiling; stopping')
  }
  console.log('look at ' + OUT_DIR_REL + '/ and choose with --choose <A-D>')
}

function choose() {
  const id = value('--choose')
  if (IDS.indexOf(id) < 0) fail('--choose takes A, B, C or D')
  const r = load()
  for (const x of IDS) { if (!r.candidates[x]) fail('candidate ' + x + ' is not rendered; the operator chooses among all four'); checkFile(r.candidates[x]) }
  r.chosen = id
  r.promoted = null
  save(r)
  console.log('chosen: ' + id + '; now run --promote')
}

async function promote() {
  const r = load()
  if (!r.chosen) fail('no candidate is chosen')
  const c = r.candidates[r.chosen]
  checkFile(c)
  const src = fs.readFileSync(abs(c.file))
  const files = {}
  for (const w of WEB) {
    let out = null
    for (const q of QUALITIES) {
      const b = await sharp(src).resize(w.size, w.size, { fit: 'contain', background: { r: 0, g: 0, b: 0, alpha: 0 } }).webp({ quality: q, alphaQuality: 90, effort: 6 }).toBuffer()
      if (b.length <= w.maxBytes) { out = b; break }
    }
    if (!out) fail(w.rel + ' stays over ' + w.maxBytes + ' bytes at quality ' + QUALITIES[QUALITIES.length - 1])
    fs.mkdirSync(path.dirname(abs(w.rel)), { recursive: true })
    fs.writeFileSync(abs(w.rel), out)
    files[w.rel] = { sha256: sha256(out), bytes: out.length, size: w.size }
    console.log(w.rel + '  ' + out.length + ' bytes')
  }
  r.promoted = { from: r.chosen, files, at: new Date().toISOString() }
  save(r)
}

function status() {
  const r = load()
  for (const id of IDS) console.log(id + ': ' + (r.candidates[id] ? r.candidates[id].file + '  ' + usd(r.candidates[id].cost_usd) : 'not rendered'))
  console.log('spent ' + usd(spent(r)) + ' of ' + usd(CEILING) + '; chosen ' + (r.chosen || 'none') + '; promoted ' + (r.promoted ? 'yes' : 'no'))
}

async function main() {
  if (has('--plan')) return plan()
  if (has('--render')) return render()
  if (has('--choose')) return choose()
  if (has('--promote')) return promote()
  if (has('--status')) return status()
  fail('say --plan, --render, --choose, --promote or --status')
}
main().catch((e) => fail(e && e.message ? e.message : String(e)))
```

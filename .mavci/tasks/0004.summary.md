## Design decisions recorded

**ADR 0006** — `.mavci/decisions/0006-what-bounds-a-caller.md`
- Separates amplification (how many upstream generations one request causes) from rate (how many requests one caller can send)
- Amplification fixed at one per request in code via `MAX_STYLES_PER_REQUEST = 1`, enforced in the route
- Rate is unbounded in this repository because there is no auth, no store and no session; fixing it requires edge controls (Vercel WAF) and provider controls (spend cap), both operator actions in external dashboards
- BotID is deferred: it would be a new dependency and deserves its own task
- Criterion 15 verifies this document exists and asserts the unbounded-rate fact, so the policy cannot be silently changed

**ADR 0007** — `.mavci/decisions/0007-one-image-per-request-and-the-deferred-timeout.md`
- Pins the per-request image count at one, with reasoning: the transport limit (Vercel's 4.5 MB response cap) makes multi-image responses impossible regardless of time
- Records three measured generation times on a real photograph (45297 ms, 45230 ms, 41392 ms), showing the 35.06 s figure recorded in task 0002 was understated by about 26%
- Notes that the timeout misclassification (slow-but-successful generation reported as `UPSTREAM_UNREACHABLE`) is known and deferred; it affects approximately two-thirds of real requests and needs re-measurement across image sizes
- Criterion 16 verifies this record exists and that the timeout constants are not changed by this task, so a silent half-fix is prevented

## Picker shape and accessibility

The style selector was a flat dropdown at 31 options. The new picker groups them into four categories by a derived property and presents them as a radio grid:

- **`classic`** (the default, outside groups) — label `Varsayılan` ("Default")
- **Four `<fieldset>` sections:**
  - `cizgi` — `Çizgi ve Mürekkep` ("Line and Ink") — 8 styles
  - `boya` — `Boya ve Fırça` ("Paint and Brush") — 8 styles
  - `baski` — `Baskı` ("Print") — 7 styles
  - `kesme` — `Kesme ve Kolaj` ("Cut and Collage") — 7 styles

Each card is a `<label>` containing a `<input type="radio" name="style">`, a preview image (or a CSS swatch if not yet rendered), the style name and a one-line description. The grid is `repeat(auto-fill, minmax(150px, 1fr))`, yielding one column at 375px and two columns from 768px — the same responsive boundary task 0001 criterion 29 enforces to prevent horizontal overflow.

**Accessibility is structural, not decorative.** The fieldset/legend/radio combination makes thirty-one options navigable by keyboard and announced as four groups by a screen reader.

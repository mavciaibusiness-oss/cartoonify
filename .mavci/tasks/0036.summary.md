## Idle timeout: the value in the code

The spec's D11.1 suggests `requestIdleCallback` with `{ timeout: 2500 }`. The code uses **2000**. Line 48 of `components/consent.tsx`:

`if (typeof window.requestIdleCallback === 'function') idle = window.requestIdleCallback(show, { timeout: 2000 })`

The other timing lines in the same effect:

- The floor: `}, 500)` (line 50). The banner is scheduled 500 ms after `load`.
- The fallback when `requestIdleCallback` is missing: `else idle = window.setTimeout(show, 1500)` (line 49).

From these numbers, the banner is shown at most 2.5 s after `load` (500 ms floor plus the 2000 ms idle timeout), or at most 2.0 s with the fallback. Both are inside the 3 s limit. The source does not record why 2000 was used instead of 2500; the spec's wording "(or an equivalent idle-or-timeout)" allows the difference, but whether the operator was asked is not recorded.

## Execution summary

This task adds Turkish and English language support with Turkish as the default at the root (`/`) and English under `/en`. Every visible string is localized, including the 31 style names and descriptions. Turkish is the source of truth; English is typed from it and enforced by type-checking at build time. ## Remarks on criterion design

**Criterion 5's equality test is structural, not semantic.** It walks both dictionaries comparing keys and confirms that every Turkish error code lives in `lib/cartoon-styles.ts` as a constant and matches the route's error message byte for byte. It does not judge the English translation; that is criterion 6 for style text and operator judgment (§11 item 7 of the spec) for the notice and other copy.

**Criterion 8's `counterpartPath` mappings are exhaustive for application routes.** The legal pages and `/contact` fall through to `/en` on the switch, which is correct: they are Turkish-only, so `/en` is the "other language" for pages the site does not maintain in both.

**Criterion 9 checks DOM order, not rendered geometry.** The notice must come before the input element in the HTML source. CSS properties like `flex-direction: row-reverse`, `grid-area` assignments, or absolute positioning could still draw it below the control on screen, which would be a defect criterion 9 cannot see. The spec (§11 item 7) names this as an observation the operator must verify on the rendered page.

**Criterion 11 is a heuristic with measured coverage.** It scans for JSX text, literal `alt`/`aria-label`/`title`/`placeholder`, and single-quoted strings with spaces. It does not see strings reached through a variable, dictionary values that go untranslated, or text in `lib/` files and the legal pages (which remain Turkish-only). The spec §9.1 item 4 measures two known gaps: text containing parentheses (like `(Amerika Birleşik Devletleri)`) passes the check, and text after a `//` comment marker passes because the scanner removes comments first. These are not defects of the code; they are limits of the heuristic.

**Criteria 15 and 16 locate `.style-grid` by line and measure its floor.** Task 0004 criterion 11 reads the first numeric `minmax(` in the file. Before this task, `.group-preview` sat above `.style-grid`, so criterion 11 was misdirecting to 190px instead of the intended 145px. Criterion 15 confirms the reordering. Criterion 16 double-checks the floor by rule name rather than position, so the two criteria cannot both pass if the floor is wrong.

## Key design decisions

**Turkish is the source; English is typed from it.** The English dictionary imports the `Dictionary` type from Turkish. A missing key or an extra key in English is a compile error in `npm run check`. The style text lives in Turkish in `lib/cartoon-styles.ts` and is translated in a separate file (`lib/i18n/styles.en.ts`), so the prompts sent to the provider stay unchanged and the translation cannot accidentally touch them.

**One root layout, not two.** The root layout stays `<html lang="tr">` to hold the legal pages and `/contact`. The English subtree wraps itself in `<div lang="en">`. On `/en` the `<html>` element still says Turkish, which is a weaker language signal than if each tree had its own root layout. The benefit is that the language switch is a client-side transition within the same root layout, so the chosen file survives switching language. The cost and trade-off are recorded in the spec §6.1 and §11 item 2.

**Legal pages are Turkish-only.** They are not translated. On `/en`, the footer links are labeled in English and marked `*(in Turkish)*`. The switch links to `/en`, which serves the same pages. This keeps a lawyer's review on one version of the text and prevents two document-revision tracks.

**The hero pair is removed, not replaced.** Both images referenced files that do not exist. This task removes the markup. The next task (§10.1) will restore the pair with a real before/after: a source portrait and its render at the new model. Criterion 12 fails if anything appears under `public/hero/`, so the pair cannot come back incomplete.

**No browser-language detection.** The language is carried by the URL. There is no middleware, no Accept-Language header inspection, and no cookie. The chosen language stays the same on every page (a URL switch) until the visitor clicks the toggle.

**ADR 0004 stays in force after this task.** Its expiry reads: *"superseded when a task describes the tree as it now stands and carries the previews in scope."* This task describes the tree as it now stands, but it removed the render work to a later task and does not carry the previews. It is therefore not superseded. ADR 0004 remains in force until the §10.1 task is approved.
